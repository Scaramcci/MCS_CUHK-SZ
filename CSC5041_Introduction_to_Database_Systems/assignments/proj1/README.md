## Environment and run commands

Tested on local Ubuntu/Linux x86_64, PostgreSQL server/client 18.6. Teacher materials do not specify a required major version. The scripts below need Python 3.11+ (standard library only); the final SQL file needs only PostgreSQL and the original database. Use a local PostgreSQL login with CREATEDB permission. Credentials are not included.

Run from this assignment directory. For a **new empty database**, choose an unused name instead of replacing an existing database:

```bash
python src/prepare_import.py
createdb proj1_fresh
psql -X -v ON_ERROR_STOP=1 --single-transaction -d proj1_fresh -f data/import/MyDATASET.sql
psql -X -v ON_ERROR_STOP=1 -d proj1_fresh -f project_release_to_students/check.sql
psql -X -v ON_ERROR_STOP=1 --single-transaction -d proj1_fresh -f src/proj1.sql
psql -X -v ON_ERROR_STOP=1 -d proj1_fresh -f tests/teacher_checks.sql
```

`prepare_import.py` removes exactly one `COMMENT ON EXTENSION plpgsql` statement from a derived local copy. The original dump tries to comment on an administrator-owned extension, which the ordinary database owner cannot do on this installation. The first strict transactional import failed at that statement and rolled back; evidence is retained. The derived file changes no table, constraint, function, or data row. It is only an initialization aid, not part of the submission.

The existing `proj1` database contains the imported teacher data, teacher checker and current solution views. The solution can be reloaded with `CREATE OR REPLACE VIEW`. Teacher checking functions themselves use PL/pgSQL; none of the submitted solutions does.
