\subsection{关系代数：需要额外补练的三个题型}
T2(a) 和两卷 Q4 的结构相近，\textbf{不能只因这些题会做，就认为 sheet 全覆盖}。下面三题为本清单自编补练，英文题干、暂不附答案。

\textbf{S1. Rename and self-join.} Given Employee(eid, name, dept, salary), where eid is the key, return the names of employees who share a department with at least one \emph{other} employee. Use two renamed copies and a join. Names may repeat.

\textbf{S2. Largest / most.} For the same Employee relation, return each department and its number of employees, but keep only departments with the largest employee count. Return all ties. Use aggregation and relational algebra; no SQL.

\textbf{S3. Count the right object.} Given Enrolled(sid, cid, term), with key (sid,cid,term), return each sid appearing in Enrolled and the number of distinct courses that student has taken across all terms. Use relational algebra. Retaking one course must not increase its count.

\textbf{补看笔记：}\,重命名/自连接：05 §5、7（中 p.44--45 / 英 p.48--49）；聚合及统计对象：05 §11（中 p.47--48 / 英 p.52）；S2 可用两次聚合或“排除有更大计数者”的思路。无需背固定变量名。

\section{3. 关系代数与映射：这些地方要单独标红}
以下是对 sheet 的适用边界说明，不是新增官方范围。

\begin{enumerate}
\item \textbf{“both”不必机械地用除法。}sheet 将 all / every / both 放在一起提示除法；但 T2(a)(iii) 明确要求\textbf{交集}。两类分别至少一个，用两个 ID 集合的交；目标集合中的每一个对象都满足，才是标准除法模式。
\item \textbf{“how many”要数对对象。}RA 先投影去重，再用 $\gamma$ 计数可表达 distinct 计数；不是所有计数都必须去重。join 产生多行时，先判断要数人、课程、选课还是连接后的配对。单独 $\pi$ 不会给出计数。
\item \textbf{“more than one”不总是只靠 $\ne$。}自连接要同时满足\textbf{业务配对条件}与“不同对象”的键不等条件；例如同部门并且 eid 不同。也可在适用时用分组计数判断数量。
\item \textbf{n 元关系的主键要从唯一性推。}sheet 的 N-side keys 提示不能当成任意 n 元关系的通用最小键算法。复习 04 §9：先问“固定哪些参与者，剩下的是否唯一”，再定候选键；无额外唯一性约束时，通常组合全部参与者键。多个 1 侧时尤其要逐个检查，不能只凭字母删键。
\item \textbf{派生属性按本课映射题不单独存。}sheet 写 derived attribute never stored；本轮标准映射按此处理。不要把这句话扩展成所有实际数据库都绝对禁止存储计算结果。
\item \textbf{复合外键遵从 sheet 的课堂规则。}要么整组匹配同一目标键，要么整组 NULL；若属性另有 NOT NULL 或属于 PK，则不能用 NULL。不要把不同目标行里的各个分量拼起来，也不要套用某产品默认行为。
\item \textbf{投影最后输出名字。}并、交、差、除法先保留 ID 粒度，最后连接实体表并输出名字；同名可能属于不同对象。自然连接匹配\textbf{所有同名列}，不一定等于题目所需连接。
\item \textbf{边界与输出属性必须看清。}below 100 用 $<100$，不是 $\le100$；“所有 CS 课程”允许选过额外课程；只投影名字会丢掉身份、只投影数值可能合并不同对象。
\end{enumerate}
