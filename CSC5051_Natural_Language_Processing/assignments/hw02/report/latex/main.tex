\begin{abstract}
An answer copied four times can still be correct. Should a data filter discard it or send it for review? We tested three prompts and two inspection-agent conditions on the same 32 GPT-4 Alpaca records, each paired with a deliberately damaged copy. Requiring full marks on four criteria kept 25--27 originals and admitted none of the 32 damaged copies under any method. Every method rejected empty, unrelated and echoed answers. Repetition accounted for all disagreements over the severity of an injected defect. A single zero-shot call per record produced as many outright rejections as the inspection agent (27/32), at an estimated CNY 0.111 rather than 0.210 for the test set. The agent retained two more originals.
\end{abstract}

\section{What qualifies an example for training?}
Instruction tuning uses an answer as a demonstration of how to carry out a request. An accurate but repetitive answer also demonstrates a style; a fluent answer can miss a constraint entirely. For each record, the judge assesses the answer against the instruction and optional input on four dimensions. \emph{Instruction following} measures compliance with constraints; \emph{correctness} measures support for factual or computational claims; \emph{relevance and completeness} asks whether the response supplies what the user needs; and \emph{clarity} covers readability and unnecessary repetition. Each score is 0 (fails), 1 (partly meets), 2 (meets), or null (cannot assess).

The judge keeps a record only when all four scores are 2, rejects it if any score is 0, and sends all other records for review. An empty optional input is acceptable. Only a valid \textit{keep} enters the selected subset $D'$ of the source records $D$. Scores of 1 and 0 therefore have the same immediate effect on admission, but only the former sends an otherwise acceptable record to a reviewer.

\paragraph{Design of the paired test.}
We sampled from the 52,002 English GPT-4 Alpaca records of \citet{peng2023}. To bound request length, eligible instructions were 20--400 characters, inputs at most 600, outputs 60--800, and the total at most 1,400 characters, with at least 95\% ASCII. We excluded instructions containing terms such as “copy”, “repeat” or “empty”, then deduplicated instruction--input pairs. Seed 20261028 selected eight development bases and 32 disjoint test bases from 25,117 eligible records. The source version is pinned to commit \texttt{38b93b75}; the data carry a CC BY-NC 4.0 licence.

Each test base supplied one original and one constructed counterpart. In groups of eight, we emptied the output, substituted a donor reply, echoed the instruction and input, or repeated the original reply four times. Donors came from outside the selected bases and shared no filtered content words with the target instruction/input. Source replies have no human quality labels, so original retention measures selection. The controlled counterparts let us ask two observable questions: did the judge exclude the injected defect, and did it reject it outright?

\section{How the judges make a decision}
Each condition received the same three record fields and rubric. The system message treated record contents as data; identifiers and defect labels stayed outside the prompts and tool. The model returned four scores, a lowercase decision and a short reason. A parser checked the keys, score values and consistency with the decision rule. The conventional prompts varied the guidance preceding that contract:

\begin{description}
\item[Zero-shot.] “Apply the supplied rubric directly.” With no demonstrations, this measures how far the criteria and decision rule alone can guide the judge.
\item[Few-shot.] Two examples showed how a single failing dimension controls the decision \citep{brown2020}. Given “Add the two integers. Respond with the number only” and input “2, 3”, the answer “5” received four 2s and a keep. For “7”, correctness alone fell to 0 and the decision was reject. These hand-written demonstrations were separate from the sampled data.
\item[Stepwise.] “Identify the instruction, its constraints, and the input context” precedes an assessment of each dimension, a check for contradictions and unsupported claims, and the final rule. This zero-shot chain-of-thought prompt \citep{kojima2022} directs attention to constraints before scoring. It uses no worked reasoning demonstrations \citep{wei2022} and collects a concise justification.
\end{description}

\paragraph{Inspection agent and control.}
The agent can \texttt{finish} with a scored assessment, \texttt{inspect} the record, or \texttt{reassess} a disputed criterion \citep{yao2023}. Its prompt requests inspection for an empty output, a reply exceeding 120 words (including uncertain cases near that threshold), or apparent sentence or paragraph repetition. Other records can finish immediately. On inspection, Python returns empty fields, character and word counts, the fraction of distinct output words and the largest word frequency. The model sees the observation and its remaining call allowance before choosing its next action. Reassessment requests another reading without adding evidence. A three-call limit bounds the cost. The control uses the same agent prompt and limit but replaces the tool measurements with a message that the observation was withheld (Figure~\ref{fig:workflow}).

\paragraph{Refining the prompts on development data.}
On four development pairs, three of 40 judgments failed because the stepwise prompt produced \texttt{Reject} instead of \texttt{reject}; all 16 agent judgments finished immediately. We spelled out the lowercase decision strings and added the inspection triggers above. The revised pilot on the same records produced 40 valid judgments; each agent condition inspected two records. We then froze the prompts before the held-out run.

\paragraph{Common model settings.}
The five methods processed the same 64 held-out records on 28 October 2026. Volcengine Ark returned \texttt{deepseek-v4-1-flash-260910}. Each request used temperature 0, \texttt{reasoning\_effort=none} and a 768-token completion cap; three workers handled the run. Holding provider thinking fixed allows a comparison of prompting instructions.

\section{The strict filter excluded every constructed defect}
All five methods withheld every damaged answer. On the 24 empty, substituted and echoed answers, every method issued an outright rejection. The remaining eight replies contained the original content four times (Figure~\ref{fig:repeats}). Zero-shot rejected three and sent five for review; few-shot and stepwise each rejected one and sent seven for review. Both agent conditions rejected three, sent four for review and produced one malformed final JSON response. Each malformed response lacked a closing brace; both counted as invalid. Across all methods, 318 of 320 judgments were valid.

\paragraph{What changes when the threshold moves?}
We reapplied two more permissive rules to the saved scores. Allowing one partial score (total at least 7, no dimension below 1) caused zero-shot to admit four additional originals \emph{and five} repeated answers. The agent admitted four repeated answers with no increase in original retention. Across methods, all newly admitted diagnostics were repetitions. \section{What did inspection buy?}
The agent requested structural measurements for 18 of 64 records; the withholding control requested them for 17. Neither selected reassessment or used a third call. Each skipped three outputs that exceeded the stated length trigger (123, 124 and 131 words). The prompt delegated the choice to the model, and these traces show where it followed or missed the instruction.

The two agent conditions differed on three diagnostic decisions and one paired success, yet their aggregate decision counts were identical. Each condition chose its own actions, so a single pair of traces cannot isolate the effect of its observation.

\paragraph{Practical choice.}
For screening similar short records under this rubric, zero-shot is the economical starting point: one call per record excluded all constructed defects, and its outright rejection count matched the agent's. Inspection supplies an auditable measurement for a severity judgment. To choose a threshold for a training corpus, the next useful evidence would be human severity labels on naturally occurring repetition and factual errors. As with other LLM judges \citep{zheng2023}, agreement among prompts from one model cannot establish human agreement. This paired test measures filtering decisions on short records; downstream training gains require a training evaluation.
