## 开卷参考资料

- [可打印 PDF](开卷参考资料/CSC5010_期中开卷参考.pdf)：25 页 A4；关键词索引、分节目录、作业题号索引、公式、中间表与例题解法。
- [LaTeX 主文件](开卷参考资料/main.tex)：十个章节源文件位于 [chapters/](开卷参考资料/chapters/)。
- [一键编译脚本](开卷参考资料/build.sh)：需要 XeLaTeX、ctex/Fandol 字体及常用 TeX Live 宏包、Python 3。无需网络。

在本考试目录运行：

```bash
bash 开卷参考资料/build.sh
```

脚本在 `results/build-日期时间-进程号/` 保存每次编译日志、PDF 中间版本和源文件哈希，最后更新开卷目录的稳定 PDF 文件名。不要使用 pdfLaTeX 编译这份中文源文件。建议按 A4 原尺寸打印，页码与 PDF 物理页一致，可双面打印；纸上可再加个人实际错题。

开卷册覆盖 HW1–HW5、HW6 P1–P5 题型及课件独有计算，**不收入 Bayesian Network 和 HW6 P6–P7**。第 09 份完整讲义仍解释网络部分，便于之后使用；它不扩大本次考试范围。
